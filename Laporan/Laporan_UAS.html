IMPLEMENTASI DAN PENJELASAN PROYEK UAS

📚 Deskripsi Proyek

Aplikasi React JS "Belajar Pintar" versi lanjutan. Proyek ini dibangun dari awal menggunakan Vite dan React dengan penambahan fitur analitik, kuis interaktif, forum, gamifikasi (pencapaian), dan dashboard instruktur. Desain dirancang menggunakan Vanilla CSS murni (tanpa Tailwind) dengan gaya premium.

1. Link Akses Live (Vercel) & Teknologi Utama

Aplikasi React JS ini telah berhasil di-deploy dan dapat diakses secara online melalui tautan berikut:
https://belajar-pintar-uas.vercel.app

Tautan repositori GitHub (Source Code Khusus UAS) dapat diakses melalui:
https://github.com/dickyafriza/belajar-pintar-uas

Aplikasi juga dapat dijalankan secara lokal dengan mengeksekusi npm run dev di dalam direktori UAS/belajar-pintar.

  • react-router-dom: Untuk navigasi multi-halaman (Dashboard, Kuis, Forum, dll).
  • @tanstack/react-query: Digunakan sebagai standar server state management (mensimulasikan pengambilan API).
  • recharts: Untuk implementasi analitik visual (grafik Garis, Batang, Pie, Area, dan Radar).
  • lucide-react: Untuk koleksi ikon SVG berkualitas tinggi.

2. State Management

Sistem ini menggunakan beberapa lapisan pengelolaan state:

  • Context API (AppContext.jsx): Mengelola status global seperti Theme (Mode Gelap/Terang interaktif) dan Profil Pengguna yang terautentikasi.
  • Reducer Pattern (quizReducer.js & forumReducer.js): Digunakan untuk menangani status yang kompleks. Misalnya, saat mengerjakan kuis, state harus melacak waktu (timer), jawaban yang dipilih, status selesai, serta mode review (tandai ragu). Begitu juga di forum untuk mengelola upvote, pencarian, dan fitur penyematan.

3. Implementasi Fitur Halaman

Terdapat lima halaman utama di sisi admin (/admin/*) yang telah diimplementasikan sepenuhnya:

  • Dashboard Analitik: Menampilkan ringkasan kognitif dengan Recharts yang memvisualisasikan waktu belajar, pencapaian kompetensi dalam format Radar Chart, serta riwayat pembelajaran.
  • Sistem Quiz & Penilaian: Menggunakan struktur Tabs untuk membagi Mode Manajemen (Daftar Kuis), Mode Mengerjakan (dengan Timer & navigasi soal), serta Mode Analitik Kuis.
  • Forum Diskusi: Thread berbasis komunitas dengan fitur Upvote, Tandai Terselesaikan, filter data, dan lencana reputasi kontributor.
  • Sistem Pencapaian (Gamifikasi): Halaman interaktif yang menampilkan Learning Path visual serta koleksi lencana kelangkaan (Common, Rare, Epic, Legendary).
  • Dashboard Instruktur: Overview kelas, pemantauan performa siswa, dan identifikasi sistematis terhadap siswa yang kesulitan.

4. Desain Premium Vanilla CSS

Desain dibangun murni dari Vanilla CSS di file src/index.css. Ini mengadopsi Design System kustom yang mencakup:

  • Variabel CSS (CSS Custom Properties): Mengatur warna dasar, bayangan (shadow), kelengkungan (radius), dan waktu transisi.
  • Tema Dinamis: Mode Gelap (Dark Mode) diaktifkan hanya dengan mengubah atribut data-theme pada document root, didukung oleh nilai variabel warna yang responsif.
  • Glassmorphism: Komponen dengan latar transparan dan efek backdrop blur untuk antarmuka yang sangat premium.

4. Forum.jsx (Forum Diskusi)

Penjelasan: Menyediakan fitur interaksi komunitas belajar antarsiswa. Dilengkapi dengan fungsionalitas pencarian data, filter tag kategori, dan pemberian upvote (voting) pada sebuah diskusi. State diskusi dikelola menggunakan pola Reducer.

// Screenshot Code: Forum.jsx
import React, { useReducer, useEffect, useState } from 'react';
import { Search, Filter, MessageCircle, ArrowBigUp, CheckCircle, Pin, Flag, Award, MoreVertical, Plus, X, RefreshCw } from 'lucide-react';
import { useAppContext } from '../../context/AppContext';
import { useForumThreads } from '../../hooks/useAppData';

const Forum = () => {
  const { user } = useAppContext();
  const { 
    data: threads, 
    isLoading, 
    addForumThread, 
    upvoteThread, 
    togglePinThread, 
    toggleSolvedThread 
  } = useForumThreads();
  
  const [filters, setFilters] = useState({ search: '', sortBy: 'newest' });
  const [showForm, setShowForm] = useState(false);
  const [newTitle, setNewTitle] = useState('');
  const [newDesc, setNewDesc] = useState('');

  const handleSearch = (e) => {
    setFilters(prev => ({ ...prev, search: e.target.value }));
  };

  const handleSort = (e) => {
    setFilters(prev => ({ ...prev, sortBy: e.target.value }));
  };

  const handleAddThread = (e) => {
    e.preventDefault();
    if (!newTitle.trim() || !newDesc.trim()) return;
    
    const newThread = {
      id: Date.now(),
      title: newTitle,
      author: user.name,
      replies: 0,
      upvotes: 0,
      tags: ['Diskusi Baru'],
      isPinned: false,
      isSolved: false,
      createdAt: new Date().toISOString(),
      description: newDesc
    };

    addForumThread(newThread);
    setNewTitle('');
    setNewDesc('');
    setShowForm(false);
  };

  const filteredThreads = (threads || [])
    .filter(t => t.title.toLowerCase().includes(filters.search.toLowerCase()) || 
                 t.tags.some(tag => tag.toLowerCase().includes(filters.search.toLowerCase())))
    .sort((a, b) => {
      if (a.isPinned !== b.isPinned) return a.isPinned ? -1 : 1;
      if (filters.sortBy === 'popular') return b.upvotes - a.upvotes;
      if (filters.sortBy === 'solved') return a.isSolved === b.isSolved ? 0 : a.isSolved ? -1 : 1;
      return new Date(b.createdAt) - new Date(a.createdAt);
    });

  if (isLoading) {
    return (
      <div className="flex items-center justify-center h-64 animate-fade-in">
        <RefreshCw size={32} className="animate-spin text-primary" />
        <span className="ml-3 text-lg font-medium text-primary">Memuat Forum...</span>
      </div>
    );
  }

  return (
    <div className="grid-4 gap-6 animate-fade-in">
      {/* Sidebar Forum */}
      <div className="card h-fit flex-col flex gap-6 sticky top-24">
        <div>
          <h3 className="font-bold text-lg mb-4">Pencarian</h3>
          <div className="relative">
            <Search className="absolute left-3 top-1/2 -translate-y-1/2 text-muted" size={18} />
            <input 
              type="text" 
              placeholder="Cari topik atau tag..." 
              className="input-control pl-10"
              value={filters.search}
              onChange={handleSearch}
            />
          </div>
        </div>

        <div>
          <h3 className="font-bold text-lg mb-4">Filter & Urutkan</h3>
          <select className="input-control mb-3" value={filters.sortBy} onChange={handleSort}>
            <option value="newest">Terbaru</option>
            <option value="popular">Terpopuler</option>
            <option value="solved">Terpecahkan</option>
          </select>
        </div>

        <div>
          <h3 className="font-bold text-lg mb-4">Reputasi Saya</h3>
          <div className="flex items-center gap-4 bg-primary-light p-4 rounded-lg">
            <Award size={32} className="text-primary" />
            <div>
              <p className="text-sm font-bold text-primary">Level 5 Contributor</p>
              <p className="text-xs text-muted">1,500 Poin</p>
            </div>
          </div>
        </div>
      </div>

      {/* Main Forum List */}
      <div className="flex flex-col gap-4" style={{ gridColumn: 'span 3' }}>
        <div className="flex justify-between items-center bg-bg-secondary p-4 rounded-lg shadow-sm border border-color">
          <h2 className="text-xl font-bold">Semua Diskusi</h2>
          <button className="btn btn-primary" onClick={() => setShowForm(!showForm)}>
            {showForm ? <><X size={16}/> Batal</> : <><Plus size={16}/> Buat Diskusi Baru</>}
          </button>
        </div>

        {showForm && (
          <div className="card animate-fade-in" style={{ backgroundColor: 'var(--primary-light)', borderColor: 'var(--primary-color)' }}>
            <h3 className="font-bold text-lg mb-4 text-primary">Mulai Diskusi Baru</h3>
            <form onSubmit={handleAddThread} className="flex flex-col gap-4">
              <div>
                <label className="input-label mb-2 block">Judul Diskusi</label>
                <input type="text" className="input-control" value={newTitle} onChange={(e) => setNewTitle(e.target.value)} placeholder="Contoh: Bagaimana cara menggunakan Context API?" required />
              </div>
              <div>
                <label className="input-label mb-2 block">Isi Pertanyaan/Diskusi</label>
                <textarea className="input-control" rows="4" value={newDesc} onChange={(e) => setNewDesc(e.target.value)} placeholder="Jelaskan pertanyaan atau topik diskusi Anda..." required></textarea>
              </div>
              <div className="flex justify-end mt-2">
                <button type="submit" className="btn btn-primary">Kirim Diskusi</button>
              </div>
            </form>
          </div>
        )}

        {filteredThreads.map(thread => (
          <div key={thread.id} className={`card flex gap-4 ${thread.isPinned ? 'border-l-4 border-l-warning' : ''}`}>
            {/* Upvote column */}
            <div className="flex flex-col items-center gap-1 min-w-[3rem]">
              <button 
                className="text-muted hover:text-primary transition-colors"
                onClick={() => upvoteThread(thread.id)}
              >
                <ArrowBigUp size={24} />
              </button>
              <span className="font-bold">{thread.upvotes}</span>
            </div>

            {/* Content */}
            <div className="flex-1">
              <div className="flex justify-between items-start mb-2">
                <div className="flex items-center gap-2">
                  {thread.isPinned && <Pin size={16} className="text-warning" />}
                  {thread.isSolved && <CheckCircle size={16} className="text-success" />}
                  <h3 className="font-bold text-lg text-primary">{thread.title}</h3>
                </div>
                
                {/* Moderation Tools */}
                <div className="flex gap-2 text-muted">
                  <button onClick={() => toggleSolvedThread(thread.id)} title="Tandai Selesai" className="hover:text-success"><CheckCircle size={16} /></button>
                  <button onClick={() => togglePinThread(thread.id)} title="Pin Thread" className="hover:text-warning"><Pin size={16} /></button>
                  <button onClick={() => alert('Laporan telah dikirim ke admin!')} title="Laporkan" className="hover:text-danger"><Flag size={16} /></button>
                </div>
              </div>

              <p className="text-sm text-muted mb-4 line-clamp-2">
                {thread.description || `Diskusi hangat seputar ${thread.category}. Mari bagikan pengalaman, error yang dihadapi, atau tips and trick yang relevan dengan topik ${thread.title} ini.`}
              </p>

              <div className="flex justify-between items-center text-xs">
                <div className="flex gap-2">
                  {thread.tags.map(tag => (
                    <span key={tag} className="badge badge-gray">{tag}</span>
                  ))}
                </div>
                <div className="flex items-center gap-4 text-muted font-medium">
                  <div className="flex items-center gap-1">
                    <span className="avatar" style={{width: 24, height: 24, fontSize: 10}}>{thread.author.charAt(0)}</span>
                    {thread.author}
                  </div>
                  <div className="flex items-center gap-1">
                    <MessageCircle size={14} /> {thread.replies} Balasan
                  </div>
                  <span>{new Date(thread.createdAt).toLocaleDateString()}</span>
                </div>
              </div>
            </div>
          </div>
        ))}
      </div>
    </div>
  );
};

export default Forum;

                <div key={i} className="relative">
                  <div className={`absolute -left-[33px] w-4 h-4 rounded-full border-2 border-white ${step.status === 'done' ? 'bg-success-color' : step.status === 'active' ? 'bg-primary-color ring-4 ring-primary-light' : 'bg-border-color'}`}></div>
                  <h4 className={`font-bold ${step.status === 'active' ? 'text-primary' : step.status === 'pending' ? 'text-muted' : ''}`}>{step.title}</h4>
                  <p className="text-xs text-muted mt-1">{step.status === 'done' ? 'Selesai' : step.status === 'active' ? 'Sedang Berjalan' : 'Terkunci'}</p>
                </div>
              ))}
            </div>
          </div>
        </div>

        {/* Kolom 2: Koleksi Badge */}
        <div className="card" style={{ gridColumn: 'span 2' }}>
          <h3 className="card-title mb-4">Koleksi Pencapaian</h3>
          <div className="grid-2 gap-4">
            {achievements.map((ach) => (
              <div key={ach.id} className={`border border-color rounded-lg p-4 flex gap-4 ${ach.isUnlocked ? 'bg-bg-primary' : 'bg-bg-primary opacity-60 grayscale'}`}>
                <div className="avatar" style={{width: 50, height: 50, backgroundColor: ach.isUnlocked ? 'var(--primary-light)' : 'var(--border-color)', color: ach.isUnlocked ? 'var(--primary-color)' : 'var(--text-secondary)'}}>
                  {ach.isUnlocked ? getIcon(ach.icon) : <Lock size={24} />}
                </div>
                <div className="flex-1">
                  <div className="flex justify-between items-start mb-1">
                    <h4 className="font-bold text-sm">{ach.title}</h4>
                    <span className={`badge ${rarityColors[ach.rarity]}`}>{ach.rarity}</span>
                  </div>
                  <p className="text-xs text-muted mb-3">{ach.description}</p>
                  
                  {!ach.isUnlocked && (
                    <div>
                      <div className="flex justify-between text-xs mb-1">
                        <span>Progress</span>
                        <span>{ach.progress}%</span>
                      </div>
                      <div className="progress-bg h-1.5">
                        <div className="progress-fill" style={{ width: `${ach.progress}%` }}></div>
                      </div>
                    </div>
                  )}
                  {ach.isUnlocked && (
                    <div className="text-xs font-bold text-success flex items-center gap-1">
                      <CheckCircle size={12} /> Selesai (+{ach.points} pts)
                    </div>
                  )}
                </div>
              </div>
            ))}
          </div>
        </div>
      </div>
    </div>
  );
};

export default Achievements;
